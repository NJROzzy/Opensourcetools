      § 5

      Method

      On inclusion. A tool enters the Atlas only if it can be used at no cost and its source is published under a recognised open licence (MIT, Apache-2.0, BSD, GPL and kin). Open-weight models are noted separately, as their licences vary.

      On assembly. A proper project is rarely one tool — it is an amalgam. A typical robotics study might braid ROS 2, MuJoCo, PyTorch and OpenCV; a language-model product might braid llama.cpp, LlamaIndex and PostgreSQL with pgvector. Read the Atlas as a set of parts, not a ranking.

      On currency. Licences change. Always verify the licence file in a project's repository before you build upon it.
